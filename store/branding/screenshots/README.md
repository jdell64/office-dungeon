# Store screenshots

Put **phone** screenshots here (PNG or JPG). For **tablet**-specific shots, use the `tablet/` subfolder.

See [`../../../docs/store/screenshot-checklist.md`](../../../docs/store/screenshot-checklist.md) for suggested captures.

Guidelines (typical store expectations):

- Use **clean device frames** or raw captures per your brand; avoid misleading UI.
- **Minimum short edge** often ~1080 px for phone; follow current Play/App Store specs before submission.
- Turn off debug overlays; use a **release** or production-like build when possible.
