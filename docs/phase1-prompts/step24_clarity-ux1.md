We are continuing the "Office Dungeon" project.

## Goal

Improve clarity so the player always understands what is happening and why.

## Requirements

### 1) HUD Clarity

Ensure HUD clearly shows:

- current energy
- current stress
- any modifiers (perk effects)

### 2) Last Action Feedback

Add a simple "last action" text area:

- shows what just happened
- examples:
  - "Took 1 damage"
  - "Gained 1 energy"
  - "Stress increased"

### 3) Game Over Clarity

When player loses:

- clearly show why:
  - "You burned out (stress)"
  - OR "You ran out of energy"

### 4) Event Clarity

Ensure:

- event choices are clearly readable
- outcomes are understandable

### 5) Mobile Readability

Ensure:

- text is readable on small screens
- no overlapping UI

### 6) No Overengineering

Do NOT:

- add dialog systems
- add UI frameworks

Keep everything simple.

## Output

Maintain current structure. Only improve clarity.
