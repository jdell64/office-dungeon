We are continuing the "Office Dungeon" project.

## Goal

Add a small retention hook to encourage "one more run".

## Requirements

### 1) Near-Miss Messaging

When player loses:

- show a message like:
  - "So close..."
  - "One more run?"

### 2) Progress Tease

If player is close to unlocking a perk:

- show:
  - "2 more credits to unlock [perk name]"

### 3) Victory Reinforcement

When player wins:

- show:
  - "You made it through the office!"
- emphasize reward earned

### 4) Quick Restart Flow

Ensure:

- restart is immediate
- minimal friction

### 5) No New Systems

Do NOT:

- add quests
- add achievements
- add notifications

Keep it lightweight.

## Output

Focus on small text/UI improvements only.
