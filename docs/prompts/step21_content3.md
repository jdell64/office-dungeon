We are continuing the "Office Dungeon" project.

## Goal

Add more predefined layouts to improve replay variety.

## Requirements

### 1) Add Layouts

Add at least 3 new layouts:

1. Combat Heavy
   - more enemy tiles
   - fewer event tiles

2. Event Heavy
   - more event tiles
   - fewer enemy tiles

3. Risk/Reward Layout
   - one path with more enemies + rewards
   - one path with fewer enemies

### 2) Selection

Ensure:

- layouts are randomly selected at run start
- existing layouts remain usable

### 3) Visual Clarity

If possible:

- lightly differentiate tile types (color or label)
- ensure mobile readability

### 4) No New Systems

Do NOT:

- add pathfinding systems
- add map generation complexity

Just expand predefined layouts.

### 5) Debug State

Expose:

- current layout id
