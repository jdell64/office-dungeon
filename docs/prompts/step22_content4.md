We are continuing the "Office Dungeon" project.

## Goal

Perform a light balance pass to improve run feel and replayability.

## Requirements

### 1) Tune Core Values

Adjust:

- starting energy
- starting stress
- enemy damage values
- event rewards/penalties

Target:

- runs last ~1–3 minutes
- player wins ~50–70% of runs

### 2) Credit Economy

Ensure:

- players earn enough credits to unlock a perk within 1–2 runs
- but not all perks immediately

### 3) Perk Impact

Ensure perks feel meaningful:

- Extra Coffee noticeably helps survival
- Calm Mind reduces early pressure
- Aggressive Reply speeds up fights

### 4) Fail State

Ensure:

- losses feel understandable
- avoid sudden unavoidable spikes

### 5) Minimal Feedback Improvements

If simple:

- add small text feedback (e.g. "-1 HP", "+1 Energy")
- improve clarity of outcomes

### 6) No New Systems

Do NOT add:

- new mechanics
- new currencies
- new UI systems

This is strictly tuning and small clarity improvements.

### 7) Debug State

Expose key values:

- player stats
- enemy stats
- last action result
