# Screenshot checklist (pre-submission)

Capture from a **clean build** (no debug labels). Prefer consistent device aspect (e.g. 9:16 phone). Export to [`store/branding/screenshots/`](../../store/branding/screenshots/) (use `tablet/` when you need separate tablet assets).

| # | Screen | Notes |
|---|--------|--------|
| 1 | **Title / main menu** | Legible logo or title; shows core mood. |
| 2 | **Gameplay** | Typical combat or map moment; HUD readable. |
| 3 | **Event / choice** | Shows a decision moment (dialog or choice UI). |
| 4 | **Run summary** | End-of-run stats or outcome screen. |
| 5 | **Perk / progression** | Meta unlocks, perks, or between-run upgrades if applicable. |
| 6 | **Premium / continue** | Honest capture of optional purchase or continue flow—required if you monetize that way. |

## Before upload

- [ ] Re-read store policies for **minimum/maximum** screenshot counts and resolutions.
- [ ] Use the same **locale** as your listing or provide localized sets.
- [ ] Avoid misleading framing (e.g. features not in the build).
